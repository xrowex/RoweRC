# APEX Wangan City test map

Download [APEX-Wangan-1.0.0-test.4.zip](https://github.com/xrowex/RoweRC/releases/download/v0.1.8/APEX-Wangan-1.0.0-test.4.zip) with [RoweRC 0.1.8](https://github.com/xrowex/RoweRC/releases/tag/v0.1.8). The city package needs the matching mod's grounded vehicle adapter.

1. Install or update RoweRC 0.1.8. Close RC Tandems to let a pending F8 update install, then relaunch.
2. Copy the intact map ZIP to `%LOCALAPPDATA%/RoweRC/Maps/Inbox`.
3. Open **F8 → Maps → Reload custom maps**, then restart RC Tandems.
4. Select **APEX Wangan City** and choose **Load / change host map**. Use the native **Drive** button if the game opens at the Bench.

Both players install the same mod and map. The host chooses the map; guests follow automatically. Maps are not downloaded from a lobby or installed by the mod updater.

- Map ID: `apex-wangan`
- Version: `1.0.0-test.4`
- Engine: Unreal 5.7
- Level: `/Game/RoweRCMaps/apex_wangan/Tandyz_Overcast_With_APEX_Repaired`
- ZIP SHA-256: `67e20405ec89230fa5db6e625f7f76b7d6f6dc7e4f5f527ba8928df4997920f0`

The 3D city geometry is retained. Road height, banking, camera height, city contacts and all four native arena limits passed local checks. This is an experimental test map: a complete lap and two-PC driving/impact acceptance remain unverified. Grounded driving is supported; airborne dynamics are not implemented. Some referenced texture images were not supplied, so some surfaces use their imported material colors.
